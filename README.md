# Tech10x — Agency Landing Page

Marketing landing page for Tech10x, an AI/dev studio for D2C brands (storefronts, AI support
bots, WhatsApp automation, store audits, MVP builds). Copy is sourced from
`../freelance-playbook/01-positioning-pack.md`.

Before shipping: replace `CONTACT_EMAIL` in `src/App.tsx` with the real inbox/WhatsApp number.

## Run

```bash
npm install
npm run dev
```
